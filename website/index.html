01 / THE PRODUCT

An assistant that belongs with you.

Navel Gazer aims to make personal AI useful without making privacy the price of admission. A local browser interface and an Electron desktop wrapper are in development, powered by local models with personal settings and memory under the user's control.

⌂

Your device first

Run supported models locally. Network activity should be visible and deliberate, not a surprise hidden in the fine print.

◉

Memory you manage

Review, change, export, or delete saved preferences and facts. No secret profile should be required for personalization.

⛨

Capability with boundaries

Models can suggest actions. The governed runtime decides which actions are permitted and records meaningful outcomes.

02 / AI GOVERNANCE

Trust is a system property, not a slogan.

Governance belongs in the architecture, the product decisions, and the way a community works.

01

Consent before access

Personal information and consequential actions require clear boundaries and meaningful user control.

02

Evidence over assertion

Make it possible to distinguish observations, inferences, unknowns, and unresolved conflicts.

03

Human authority stays visible

Permission checks, confirmations, and recovery paths should be understandable rather than buried.

04

Failures should be contained

A broken model or connector should not silently compromise unrelated resources or user data.
